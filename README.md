今回新たに使用したUIは、expander,metric,toggleの三種類です。expanderはsidebarを消すことができ、グラフの視認性が向上します。
metricは、グラフ上の数字の視認性を向上させています。今回のグラフは、高さでの比較しかできないため、上の数字が重要になります。そのため、metricで強調し否が応でも目にとまるようにしています。
toggleは、グラフの表示をするかしないかを決定します。先ほども言った通り、グラフでは高さ以外での比較ができず、正確性に欠けます。そこでtoggleを導入し、数字だけで差を比較したいというときのために、導入しました。
